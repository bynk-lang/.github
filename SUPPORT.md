# Getting help

- **Learning Bynk:** the [Bynk Book](https://bynk-lang.org/book/) and
  [bynk-lang.org](https://bynk-lang.org).
- **Bug or unexpected behaviour:** open an issue in the repository concerned.
  For the compiler, language server or editor extension that is
  [`bynk-lang/bynk`](https://github.com/bynk-lang/bynk/issues).
- **Language change ideas:** these go through the increment-proposal process in
  [`bynk-lang/bynk`](https://github.com/bynk-lang/bynk/blob/main/design/proposals/README.md).
- **Security issues:** do not open an issue; see
  [SECURITY.md](SECURITY.md).
- **Conduct concerns or anything else:** <hello@bynk-lang.dev>.
